# Nidhi Numerologist — interview task

Responsive front-end website with three pages:

- `index.html` — Home page
- `login.html` — Login page
- `register.html` — Create account page

Open `index.html` directly in any modern browser. It includes a responsive navigation menu, a client-side life-path calculator, password visibility control and form validation feedback. Forms are front-end demos only; they intentionally do not collect or send credentials.

Content topic supplied by the task references https://www.charrugupta.com/. Branding, layout and code are newly created for **Nidhi Numerologist**.
